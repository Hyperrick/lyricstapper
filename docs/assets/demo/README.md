# Demo assets

The README demo shows a real lyricstapper session using:

- `a-thousand-years-demo.mp3`, an 11.3-second vocal excerpt from
  [“A Thousand Years” by Josh Woodward](https://www.joshwoodward.com/song/AThousandYears)
- `lyrics.txt`, the four sung phrases used in that excerpt
- `lyricstapper-demo.gif`, the silent GitHub workflow and result preview
- `lyricstapper-demo.mp4`, the same Remotion edit with the vocal excerpt during timing and result playback

To try the workflow, choose the MP3 in Source, paste `lyrics.txt`, prepare the
four lines, start playback and hold `Space` while each phrase is sung. Then
switch to Fine-tune, Style or Export.
